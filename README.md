# 💎 نظام التسعير الذكي للعطور - Pro

نظام احترافي متكامل لمقارنة وتسعير العطور باستخدام الذكاء الاصطناعي

## ✨ المميزات

### 🎯 المطابقة الذكية
- 4 خوارزميات من RapidFuzz لدقة 98%+
- استخراج ذكي للعلامة التجارية والحجم والنوع
- متوسط مرجح للمطابقة

### 🤖 الذكاء الاصطناعي
- Gemini Pro متصل في كل قسم
- تحليل ذكي لكل منتج
- اقتراحات تسعير دقيقة
- محادثة مع خبير تسعير

### 📊 لوحة القيادة
- إحصائيات شاملة ولحظية
- رسوم بيانية تفاعلية
- عداد الوقت
- تقارير مفصلة

### 🎨 التصميم
- واجهة عربية احترافية

3. ابدأ المقارنة!

## 📖 الاستخدام

### 1. رفع الملفات
- قم برفع ملف منتجاتك (Excel أو CSV)
- قم برفع ملف المنافس
- اختر الأعمدة المناسبة

### 2. المعالجة
- اضغط "بدء المعالجة"
- انتظر حتى تنتهي المطابقة
- شاهد النتائج الفورية

### 3. تحليل النتائج
- استعرض لوحة القيادة
- راجع كل قسم (رفع سعر، خفض سعر، إلخ)
- استخدم AI للتحليل العميق

## 📊 الخوارزمية

### نظام المطابقة المتقدم

1. **التنظيف:** إزالة الأحرف الخاصة
2. **الاستخراج:** العلامة، الحجم، النوع، الجنس
3. **المطابقة:** 4 خوارزميات (Ratio, Partial, Token Sort, Token Set)
4. **المتوسط المرجح:**
   - الاسم: 35%
   - العلامة: 30%
   - الحجم: 15%
   - النوع: 10%
   - الجنس: 10%

### قواعد القرارات

- **رفع سعر:** سعرنا أقل بأكثر من 10%
- **خفض سعر:** سعرنا أعلى بأكثر من 5%
- **موافق:** الفرق ضمن ±5%
- **يحتاج مراجعة:** المطابقة < 85%
